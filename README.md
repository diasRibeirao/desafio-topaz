# Encurtador de URL

Desenvolver um sistema web que receba uma URL digitada  pelo usuário e retorne uma URL encurtada, que ao ser  acessada, deverá fazer o redirecionamento para URL original.

## Tecnologias

- Java 8
- Maven
- Java EE 7
- JAX-RS
- CDI
- WildFly 10

## Build

Execute:

```bash
mvn clean package
